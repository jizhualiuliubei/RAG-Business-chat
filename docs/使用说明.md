## 登录与角色

登录需要企业代码、用户名和密码。系统平台资产企业代码为 `system`。企业员工不能自助注册，只能由企业管理员或系统管理员创建。

| 角色 | 可用功能 |
| --- | --- |
| 系统管理员 | 企业管理、用户管理、平台模型配置、平台资产、审计日志、代管企业。 |
| 企业管理员 | 本企业员工管理、模型 Key 配置、知识库治理、RAG 评测。 |
| 企业员工 | 使用本企业知识库问答、查看自己的会话、上传当前会话附件。 |

## 企业管理

系统管理员可以创建企业、审核企业管理员注册申请、启用/禁用企业、软删除企业、查看企业模型配置状态和审计记录。

企业状态：

| 状态 | 含义 |
| --- | --- |
| 待审核 | 企业管理员提交注册后等待平台审核。 |
| 已启用 | 企业可正常登录和使用。 |
| 已拒绝 | 注册申请被拒绝，保留拒绝原因。 |
| 已禁用 | 企业被系统管理员停用，账号不能登录。 |
| 已删除 | 软删除，默认隐藏但保留数据。 |

## 模型配置

企业管理员需要配置：

- DeepSeek API Key、Base URL、模型名。
- SiliconFlow API Key、Base URL、Embedding 模型名。

保存前可以点击连接检测。检测不会自动保存配置，只有点击保存才会写入数据库。

## 知识库与文档

企业管理员可创建知识库并上传文档。支持 DOCX、PDF、TXT、CSV、XLSX/XLS。上传后系统会解析、切片、向量化并写入 Zilliz。

文档状态：

| 状态 | 说明 |
| --- | --- |
| 解析中 | 后台正在解析、切片和向量入库。 |
| 已完成 | 已成功入库，可参与检索。 |
| 失败 | 可点击失败原因查看错误。 |

## 问答与引用

用户选择知识库后提问。回答会尽量引用来源，引用区展示来源文档、知识库、相似度和片段摘要。问题没有知识库依据时，系统会倾向于说明无依据，而不是编造制度。

## 会话附件

提问时可以上传附件。附件只在当前账号当前会话内可用，不进入企业知识库。后续追问会同时检索企业知识库和会话附件。

如果附件与企业知识库冲突，回答会并列说明冲突：知识库依据是什么，附件显示什么，不能直接合并成确定结论。

## RAG 评测

评测中心支持：

- 内置企业规模 360 题基准。
- 上传自定义题集。
- AI 辅助生成草稿题集，审核后才能运行。

模式：

| 模式 | 说明 |
| --- | --- |
| retrieval | 只评测检索命中，不调用生成模型。 |
| full | 执行检索、生成、评分和报告汇总。 |

报告包含 Top-K 文档命中率、章节命中率、答案覆盖率、证据命中率、引用正确率、拒答正确率、耗时和 Token。
